# 物资 Excel 模板与报表

本说明对应0.14.1候选源码，发布状态见[版本说明](CHANGELOG.md)。物资信息10列、库存13列沿用0.12.0合同；0.11.1的旧物资模板为6列，仍兼容读取。更新后请从程序重新下载模板，旧发布目录中的附件保留原样。物资信息库现位于物资设置，期初／补录和领用入口位于库存。

## 选择正确的文件

| 页面或文件 | 工作表 | 用途 |
| --- | --- | --- |
| 物资信息库：下载导入模板／导出Excel | 物资信息，10列 | 新建或复用物资信息，不改变库存 |
| 期初库存／存量补录：下载导入模板 | 期初明细，13列 | 导入已有物资的数量及批次信息，先形成草稿 |
| 期初／补录单：导出回导明细 | 期初明细，13列 | 将该单明细复制到新草稿，不恢复原单状态或流水 |
| 库存：导出回导明细 | 库存导入明细，13列 | 复制当前正库存批次到新草稿，核对后才确认入库 |
| 库存文件中的库存、批次库存 | 汇总及前七列与页面一致的批次报表，后附位置等详情 | 查看库存；不要把汇总行当成导入明细 |
| 无金额权限：导出Excel（仅查看） | 脱敏报表 | 查询归档，不能直接回导 |
| 申报／验收历史、领用申请导出 | 对应历史报表 | 查询归档，不支持重新导入执行业务 |
| 申报单：下载申报单／原单Excel | 申报单信息、申报明细、填写说明 | 固定指定修订，含厂家、核对勾选和手填实到栏；用于纸面核对，不用于回导 |

新模板与报表统一冻结首行、中文表头、列宽、文本换行及数值对齐。填写说明标注程序生成时的模板版本；实际导入仍按表头和内容校验，不按文件名判断。

申报原单Excel、二维码和纸面核对单读取同一不可变修订，不随验收进度变化。纸单可在“查看／打印原单”中调用系统打印或保存PDF；每次到货在纸上勾选后，将当次照片或扫描PDF上传到对应到货登记，不能用上传代替验收入库。后续受控修订生成新版本，旧纸单扫码仍查看原修订并提示已有新版。

“批次库存”前七列为入库时间、物资名称、数量、规格、单位、厂家、备注；后附仓库、区域、批号、有效期、存放位置、物资备注，有金额权限时另含批次分摊金额。该页用于查阅；可回导页仍为完整13列，不要混用。

## 填写规则

物资信息库10列依次为：**物资名称、规格、单位、物资分类、管理方式、物资备注、CAS号、纯度／浓度、储存条件、SDS链接**。前五列必填，其余可选；分类和管理方式使用已有选项，名称／规格／单位可参考已有值或填写新物资。管理方式为“逐件”或“数量”。化学试剂分类在网页展开试剂字段；已保存字段不因切换分类而清空。CAS校验格式和校验位；SDS只接受无嵌入账号密码的完整HTTP(S)链接，不自动下载附件。

旧6／5列及旧编码模板仍可导入，省略的新字段保留原值。新10列遇到同身份物资而分类、管理方式、备注或试剂字段不同，将按具体列报冲突，不覆盖已有资料；需要纠错请在物资信息库的“编辑”中填写原因。完全相同的停用资料回导只计为已存在，保留停用状态；导入不会启用物资，新登记前须由管理员恢复启用。

库存回导／期初明细13列依次为：**物资名称、规格、单位、区域、仓库、数量、总金额（元）、批号、有效期、存放位置、零金额原因、厂家、备注**。前七列必填；总金额为零时，零金额原因必填。当前版本仍逐行填写区域及仓库，没有单据头默认值或四列简化模板。

- 名称、规格、单位须对应同一条已建立的物资信息；各列下拉独立，不能保证任意组合都有效。
- 区域、仓库、分类填写中文名称，不要求填写系统内部编码。参考下拉最多5000个选项，导入时仍会核对有效性和歧义。
- 存放位置参考包含已启用的中文库位完整路径和已有自由文本位置，支持选择也可填写新文本。库位字典不是库存，导入不会自动新建库位节点或移动既有实物。
- 数量大于零，最多3位小数；逐件管理须为整数。金额填写本行总金额，最多2位小数。
- 批号、有效期、存放位置、厂家及批次备注可选填；日期使用`YYYY-MM-DD`文本。同批次位置须一致，空位置沿用当前批次位置。
- “物资备注”描述物资本身；库存明细中的“备注”描述入库批次，两者分别保存。
- 数据从第2行开始，保留首行表头及列顺序，不增加合计行。原样回导物资信息会复用已有记录；分类、管理方式或备注冲突时不会覆盖原记录。

每文件最多5 MiB、每次1–5000条明细；逐件入库每单最多生成1000个独立码，超出须拆单。只接受未加密`.xlsx`，不接受公式、宏或外部链接；公式计算结果请先粘贴为值。

## 导入错误与重复登记

导入失败会显示工作表、实际行号、列字母、字段、输入值及原因；多处错误显示前200条和错误总数。所选文件保留，修改原文件后可重新上传。当前版本没有错误回填Excel下载。

整份校验通过才写入。库存导入只追加草稿明细，不自动扣减、覆盖或去重现有库存；核对后确认入库才生效。将现有库存再导入并确认，会新增库存，不能用回导代替备份恢复。

物资JSON备份要求空的新业务库及恢复权限；不会通过Excel回导保留原流水和单件码。0.14.1格式为schema8，含到货登记、资料版本及历次附件；在线备份仍受附件总量20MiB／JSON25MiB限制，大量拍照资料请使用[完整备份恢复](BACKUP_RESTORE.md)，不要复制运行中的PostgreSQL物理目录。0.11.1同步修正期初／补录明细恢复上限，使其与5000行导入上限一致，单件1000件及备份容量等限制保留。

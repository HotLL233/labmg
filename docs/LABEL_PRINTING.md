# 逐件标签与 BarTender 打印

标签模板和逐件 CSV 始于 0.5.0，**0.7.0 已公开验证版**新增内置 DL-886A（NEW）打印面板；PostgreSQL 18 业务编码继续复用。用户本机的 BarTender 2016 R7（`bartend.exe` 产品版本 11.0.7.3146）安装信息此前仅作只读核对；已有 Windows USB 驱动用于打印 DL-886A（NEW）。没有把安装路径存在当作真实打印验收，也没有调用打印机、激活软件或执行安装目录内其他工具。

**0.8.1 本轮仍在开发，尚未发布。** 下文的纸张、方向及预览改动对应当前源码，不代表 0.8.0 或更早冻结镜像已包含这些功能；旧版验证记录保留，当前结果另行注明。

## 一瓶／一件一条记录

物资信息库（原称“主档”）选择“逐件管理”，验收或期初／补录单入库时按整件数量生成固定编码。信息库 Excel 导入本身不生成实物或标签，确认入库后才生成。打开对应单件列表，选择“打印标签”或“导出 BarTender 数据”。一次最多 1000 件，历史标签重印使用原编码，不新增库存、不消耗新流水号。

旧物资保持原有数量管理，不能按数量猜测历史上每瓶的身份。批次二维码只定位批次；批次打印不能代替逐件台账。整件领用仍需人员申请、物资管理员确认并选择在库实物。

## 网页标签模板

在物资页点击“标签模板”，可修改纸张宽高、水平／垂直校准偏移，以及每个元素的位置、尺寸、字号和显示状态。毫米从纸张左上角起算，字号单位为pt。0.8.1提供已确认的60×40mm、38.5×30.5mm两种纸预设、自定义宽高和横纵方向，选择规格或方向时按比例适配已有网页布局；校准偏移保留毫米值并参与越界检查。预览显示真实码图，文字溢出标红，打印前拒绝越界或文字裁切；这些设置仍须与Windows驱动一致，不是已完成硬件校准。

示例数据的 Code128 和二维码实际生成后供预览，后续修改布局复用同一图片；这只是网页标签预览，不是 BarTender `.btw` 或打印驱动的原生预览。无效尺寸或偏移会清除旧预览并指出错误，防止把上一次有效版式误认为当前设置。模板仍使用 schema 1；旧模板中不合规的校准偏移会保留供修正，不静默丢弃。示例文字被裁切时标红并提示字段，保存按几何边界校验；打印前再检查实际所选实物的文字，避免用示例名称长度限制真实数据。

“条码铺满行宽”保留编码、条码高度与纵向位置，只将条码框扩展至左右约各留 1 mm，并计入校准偏移。自定义布局需查看是否遮住同一行的其他元素。窄纸上的长 Code128 仍可能过密，必要时取消 Code128 的“显示”、保留二维码，再保存模板；扩大版面或先试打回扫，不能靠缩短已入库编码解决。

模板只保存于**当前浏览器和网站地址来源**，不保存业务数据；清理站点存储、从 HTTP 改为 HTTPS、换端口／域名、浏览器或电脑后需要重新导入。用“导出模板 JSON”保存配置，其他电脑用“导入模板 JSON”复用。不要将浏览器模板当作业务备份。

## 内置 DL-886A（NEW）打印面板

从单件列表点击“打印本页条码／二维码”或“打印本组全部标签”，打开内置打印面板；批次二维码入口也使用同一面板。待所有条码图片加载后，才能打开系统打印窗口。

1. 0.8.1面板可直接选择两种规格、横纵方向、自定义宽高和毫米偏移，预览随输入更新，无需关闭重开。可“记住纸张与布局”保存到本浏览器；未保存时仅本次生效。样式与每页尺寸使用同一设置，Windows打印窗口仍须选择一致的纸张与方向；没有预设未确认的硬件DPI或驱动命令。
2. 填写“起始张”和“结束张”，从 1 开始且包含两端；下方预览只显示这个范围。每件仍对应原有固定编码，选范围或重印不会新增库存、实物或流水号。
3. 点击“试打所选首张”，仅把选中范围的第一张交给系统打印窗口；窗口关闭后预览恢复原范围。扫码核对标签与实物编码，再根据偏移调位置。
4. 点击“打开系统打印窗口”，打印选中范围。选择已安装且能正常工作的 DL-886A（NEW）驱动，驱动与网页设置相同纸张宽高，缩放 100%、每张 1 份，关闭页眉、页脚和适应页面。不要再在驱动中增加份数或序列化。

预览与按钮支持手机查看；USB 打印应在连接打印机的 Windows 电脑浏览器操作。面板没有读取打印机清单或指定设备名称的网页接口，`window.print()` 打开浏览器／系统打印窗口，由用户选择驱动并确认；不能把群晖上的网页等同于本机 USB 打印服务。官方接口说明见 [MDN Window.print()](https://developer.mozilla.org/en-US/docs/Web/API/Window/print)，其参数为空，不提供指定打印机参数。本节网页打印面板不额外安装插件、桥接服务，不静默打印，也不嵌入或自动打开 BarTender 设计器；独立 Windows 助手见后文。

打印窗口每页一张标签。较长编码、小标签、热敏浓度及清晰度都影响识读；不能只看预览判断物理可读。

0.7.0 冻结源码经真实隔离 Edge 检查 37/37，390／768／1440px 共 6 张截图已目视，覆盖已加载码图、范围、首张试打、无效范围及 BarTender 导出；报告为 `artifacts/cache/0.7.0/label-ui/report.json`。这是桌面视口模拟和合成记录，`window.print()` 被拦截以核对实际选中标签，没有打开系统打印窗口、访问业务库或执行 USB 打印，仍须按下文现场试打。

0.8.1 当前网页标签与原前端联合测试 **63/63 通过**（18 项标签、45 项前端）。真实隔离 Edge 使用合成记录，在 390／768／1440px 三种视口完成 **110 项检查、9 张页面截图**，无未捕获浏览器异常。另输出 **4 份双页 PDF**，分别为 60×40、40×60、38.5×30.5、30.5×38.5 mm，核对每页尺寸与方向；这是 CSS／虚拟 PDF 验证，不能证明打印机走纸、Windows 驱动或 USB 输出正常。

本轮报告为 `artifacts/cache/0.8.1/labels/report.json`，状态明确记录为 **`passed-with-limitations`**：固定合成长 Code128 在小纸直接按比例缩小后未解码；38.5×30.5 mm 横向使用“条码铺满行宽”后可从 DPR 3 截图解回原码，纵向实际宽 30.5 mm 时即使加宽，截图仍未解码。60×40 mm 两方向的 Code128 和两种纸各方向的二维码均解回准确内容。原失败报告保留，这项窄纸限制没有改写成通过，也没有仅凭截图失败就禁用所有打印。上述检查不访问数据库、NAS 或真实 BarTender，不打开系统打印窗口，不是物理标签识读验收。

网页通过 Windows 系统打印窗口使用 USB 打印机，无需把 USB 接到群晖。打印对话框是否实际打印由操作人员决定，系统不把打开窗口视为打印成功。

## BarTender 连接 CSV

从单件列表导出 `labos-bartender.csv`，这是 UTF-8 BOM、逗号分隔、双引号包围字段的文本数据库；每行对应一件实物，所有编码保留原文本和前导零。该数据用于 BarTender 的文本数据库连接，**不要双击用 Excel 自动转换或执行内容**。自由文本可能以 `=`、`+` 等字符开头；CSV 按原值提供给打印软件，不插入会改变条码的撇号。业务 Excel 导出另走安全的 XLSX 文本单元格。

1. 在现有 BarTender 设计器中新建标签或打开已有 `.btw`，选择当前已安装的 DL-886A（NEW）驱动，并按实际标签纸设置尺寸。
2. 打开“数据库连接设置”，新增文本文件数据库，选择刚导出的 CSV。设置 UTF-8 编码、逗号分隔、双引号限定、首行为字段名。2016 不同语言／版本的菜单名称可能略有差异；以本机向导为准。
3. 把 `Code` 绑定到 **Code128 条码**对象与编码文本；把 `QRPayload` 绑定到 **QR Code** 对象。不要让 BarTender 给 `Code` 再加前缀或流水号。可只保留所需的一种码。
4. 将其他字段拖到文本对象，设计位置、大小和字体，保存自己的 `.btw` 模板。以后替换为新导出的同名 CSV，刷新连接并预览记录即可复用。
5. 打印时每条选中记录 **1 份**，关闭额外序列化；选择需要的记录。误选多份只会重复标签，不会在业务系统新建实物。

| 字段 | 内容 |
| --- | --- |
| Code | 业务系统已生成的单件固定编码 |
| QRPayload | 系统完整单件二维码内容，按原文绑定 |
| Name / Specification / Unit | 物资名称／规格／单位 |
| CatalogCode | 规范物资主档编码 |
| Region / Warehouse / Location | 归属区域名称／仓库名称／存放位置（较早数据缺少仓库名称时保留原编码） |
| Batch / ExpiryDate / Status | 批号／有效期／单件状态 |

CSV 是导出时的快照，位置或状态变化后需重新导出。打印面板中的“导出 BarTender 数据”导出本窗口加载的全部实物，不受打印起止张范围影响。0.6.0 起继续用 CSV 提供打印数据，配套 Compose 不公开 PostgreSQL 端口给打印软件，也不让 BarTender 修改业务数据库；业务变更仍须经过系统的权限、事务及库存流水。0.5.1 及更早版本使用 `labos.db` 的限制属于历史 SQLite 部署，不能把旧文件连接方式套到当前数据库。0.7.0 仅有网页／CSV；0.8.0 新增下节的独立 Windows 打印助手，未实现 BarTender 命令行路线。

官方参考：[数据库连接与字段拖放](https://help.seagullscientific.com/2022/en/subsystems/gsm/content/GS_User_Databases.htm)、[文本文件编码与分隔设置](https://help.seagullscientific.com/10.1/en/Content/HIDD_DB_WIZARD_ASCII_PAGE.htm)、[打印份数与序列化](https://help.seagullscientific.com/2021/en/Content/Printing_Label_Formats.htm)。官方在线帮助版本不同于本机 2016 R7，本文只复用数据源、字段绑定与记录打印逻辑，不将新版本界面当作本机实测。

## 原生 `.btw` 与直接调用

0.8.0 源码增加原生母版上传、打印站和任务，以及在已登录 Windows 用户会话运行的 PowerShell 7 助手。物资页“BarTender 打印”管理入口及单件列表选件入口按权限显示；手机可建立任务，由连接 USB 的 Windows 助手调用 COM。服务端重新取数建立快照，每件一张，不创建新编码或改变库存。引擎已提交与人工确认分开，超时／断线结果不明不自动重印。

0.8.1补充任务纸张覆盖、站点诊断、双击菜单、同用户登录后台和原生模板图预览。PNG由Windows助手生成且不调用Print，网页轮廓实时更新不等于BTW或驱动实时渲染；缩小原生母版需制作匹配尺寸版本，不能复用网页自动缩放规则。

助手还提供`-DeriveTemplate`：修改母版已有对象后由`SaveAs()`另存`.btw`，不是任意HTML／JSON转换。命令、字段、权限和恢复见[打印助手指南](BARTENDER_AGENT.md)。本轮只有只读COM诊断，无模板生成、导出或物理打印证据；实际许可、母版、送料与USB效果仍需现场校准。

最初调研与官方 2016 依据保留在[BarTender 接入分析](BARTENDER_INTEGRATION.md)。其中“尚未接入”是开发前状态，由本节源码实现替代，不代表硬件验收已经通过。`Application.XMLScript()` 在2016要求 Enterprise Automation，本轮采用 COM `Format.Print()`／`SaveAs()`，仍需核实 Automation 或 Enterprise Automation 授权。

## 尚需现场确认

网页与导出数据可以自动验证；实际纸张尺寸、驱动参数、USB 输出、热敏效果及 DL-886A（NEW）标签识读必须在目标打印机试打。手机实时扫码另需[可信 HTTPS](SCANNING_HTTPS.md)，仅使用 HTTP 群晖 IP 无法由网页代码解除浏览器限制。

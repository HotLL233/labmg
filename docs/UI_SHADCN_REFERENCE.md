## 范围

使用原生 HTML、CSS、JavaScript，复用现有 V2 离线原型的合成数据和交互。无需安装依赖、启动服务或连接数据库；本页没有接入 React、shadcn/ui、ReUI 或任何付费区块源码。

新增 HTML 独立保存，原 `ui-unified-v2.html` 和正式 `src/public/` 均不修改。业务版本、包、标签及 NAS 不变。浅色侧栏及黑色主按钮属于本次待评审的视觉选择，不替代现行施工卡。

## 页面与布局

| 页面 | 参考重点 |
| --- | --- |
| 库存台账 | 默认打开；七个业务字段保留，名称／编码分层，数量对齐，长备注展开全文 |
| 申报列表 | 页面标题与动作同排；搜索、高级筛选、快捷状态筛选分层；10／20／50 分页 |
| 按单验收 | 按需切单、全宽八列、厂家和位置常驻；窄屏同 DOM 重排，差异按需展开 |
| 详情 | 1120px 限宽、无字段卡片分组、基本信息／批次与单件／来源流水切换 |
| 短表单 | 760px 限宽，清楚的标签与分组；取消和保存可达，未保存离开需确认 |
| 设置 | 1040px 内容区，局部导航和编号规则表；不为少量内容撑满空白面板 |

保留合成档案列表以比较共享组件。所有模拟数据只保存在本页内存中，刷新即重置；模拟入库不是数据库事务、真实幂等或业务验收。

## 可操作内容

- 搜索、日期／状态／分类筛选、快捷筛选、分页和无匹配空态。
- 查看详情、批次与单件返回、新建或编辑本地样例、修改编号示例。
- 本地验收选择、校验、成功、结果待确认和按原内容重试演示。
- “本页动作 → 导出 CSV”下载当前页合成记录，采用现有 CSV 单元格保护规则；不冒充正式 Excel 导出或目标表格软件兼容性验收。
- 手机同一份表格 DOM 重排，导航、菜单和底部操作保留。

工具菜单中的资料、扫码、导入及其他预览入口只展示内存合成数据，不连接真实摄像头、文件上传或业务服务。

图标继续使用既有原型的静态 Lucide 几何数据，HTML 内保留原 ISC／Feather MIT 声明；无 CDN、字体服务或其他外部资源。

怎么验证这份原型是否真的"手机可用"

  • 把浏览器窗口拖到 390px 宽，或直接用手机打开 ui-redesign.html：侧栏变抽屉（点左上 ☰）、底部出现 5 项 tab、表格自动变卡片。
  • 在验收页点任一明细 → 底部条点「办理验收」→ sheet 升起；点遮罩、Esc 或右上 × 关闭。
  • 检查项：页面整体无横向滚动、输入框不放大、底部条不被手势条遮住、所有可点元素 ≥44px。
  • 这不是"手机精简版"：验收、库存、申报、领用、审批、退库、管理页在手机上都能走完。唯一例外是 Excel 批量导入与打印排版（浏览器能力限制，需在界面说明原因）。

# 变更记录

## 0.1.1

- 将服务端和静态前端整理到 `src/`，检查与打包脚本整理到 `scripts/`。
- 将环境变量示例移到 `config/`，Docker 配置移到 `deploy/`，增加开发和版本说明。
- 本地数据库、附件和日志统一放在忽略提交的 `var/`；开发模式默认使用独立的 `var/development` 和 3001 端口。
- 通过 `LABOS_RUNTIME_DIR` 指定运行根目录；环境变量示例不自动加载。
- 扩展语法检查范围至全部 JavaScript；部署包输出到 `artifacts/labos-0.1.1.zip`，并保留整理后的目录结构。
- 约定 `main` 为稳定分支、`develop` 为开发分支、`feature/*` 为功能分支；以 `v0.1.1` 标记整理版。

本版是项目组织与运行目录调整，不包含已知权限、密码存储或并发业务问题的修复，也不改变当前 SQLite 与本地附件的存储方案。

# 版本更新说明

本文件是项目统一的版本更新记录。以后新版本在本文件中新增，按新版本在前排列，保留所有历史版本；不要另建每个版本的说明文件。

开发中的变更先加入“未发布”。实际发布时新增真实版本号与日期，将对应内容归入该版本，并同步 `package.json`、Git 标签和相关文档。版本条目记录功能变化、修复、兼容性或数据迁移影响及验证结果；未执行的验证须如实说明。

## 0.2.0-rc.5（2026-10-16，自动创建部署数据卷候选版）

- Compose 默认由 Docker 自动创建按项目与版本隔离的命名卷，解决首次部署依赖预先存在的宿主机目录的问题。无需手工创建数据文件夹；一次性初始化成功后正常退出，应用再启动。
- 初始化以 root 仅准备运行根及 data/uploads/logs 四个目录的属主和 owner 权限，拒绝非法 UID/GID、符号链接及非目录；业务应用继续非 root 运行，不递归更改已有数据库或附件，不以 root 启动数据库。
- `LABOS_DATA_DIR` 仍可指定已有宿主机目录，须保留真实路径和原 UID/GID；不自动搬迁旧数据。默认新卷为空，普通 down 保留卷，日常升级不要使用 down --volumes。
- 群晖说明补充缺失挂载目录排错、命名卷备份与升级，以及复用两架构 TAR 同步自有国内镜像仓库的方法；尚未配置目标国内仓库或自动双仓库发布。
- 验证：18 个 JavaScript 文件语法通过，普通回归 26 项通过、1 项 Docker 按设计跳过；临时 amd64 镜像的 Compose 专项通过，覆盖从不存在的卷启动、四目录实际属主及非 root 用户、首设/登录、重建后账号/记录/附件与既有文件元数据保留，以及拒绝符号链接且目标权限不变。默认卷、绝对 bind、旧相对 bind 的配置解析检查通过，测试项目和卷清理完成。正式双架构产物和发布结果随后按实际报告补记；未在真实群晖或国内镜像仓库验收。rc.4 及旧版本标签和产物保持不变。
- 正式发布：冻结源码 `b067c8c`，两架构 TAR 的归档/平台/OCI 及完整 Compose 专项均通过，ARM64 为模拟。Actions `38863733909` 推送多架构镜像成功；空 Docker 配置下双架构匿名实际拉取、原始索引/manifest/config 摘要及冻结正式 YML 的自动建卷、初始化、非 root、首设和重建持久化验证通过。公开 Release `414643295` 的 10 附件大小/摘要及匿名网页、YML、环境示例下载通过；匿名 API 达限后仅元数据用已有凭据核验。源码 ZIP 排除私密运行文件、真实数据库 3 文件摘要、main 和 rc.4 版本保持不变。

本版同时纳入 rc.4 冻结后的工具和部署说明跟进：
